# Presentation script outline (max 15 minutes)

Tip: record your screen with the live app open and talk over it. Keep it relaxed, like showing a friend.

| Time | Part | What to say / show |
|---|---|---|
| 0:00–1:00 | **Hook** | "I've played 210 hours of Counter-Strike. But am I actually getting better? And what should I change? I built a coach out of my own data to find out." Show the app for 3 seconds. |
| 1:00–2:30 | **Who I am + idea** | Short intro. Why CS (fun, my friends, FACEIT + Premier). The question: _what should I change to win more?_ |
| 2:30–4:00 | **The video** | "Become a Data Storyteller with Streamlit": what it taught (data + visuals + narrative). Why I chose it (see `video-choice.md`). |
| 4:00–5:30 | **Topic in simple words** | What data storytelling is, what Streamlit is, the strengths/pitfalls (small numbers lie, correlation ≠ causation). |
| 5:30–6:30 | **Getting the data** | FACEIT API = library card. Show the data table. Mention the key is kept secret in Streamlit Secrets. |
| 6:30–11:30 | **Live demo (the main part!)** | Go through the tabs as a story: 1) big numbers, 2) Coach tips, 3) check one tip in Overview (K/D trend + maps), 4) When I play, 5) Teammates, 6) Aim per map. For each: question → what the chart shows → what I learned. |
| 11:30–13:00 | **Experiments & process** | Version 1 screenshot → version 2. Things that went wrong (jumpy chart, same colours, slow teammate loading → caching, minimum 3 games). Working with AI as someone who doesn't code. |
| 13:00–14:15 | **Decisions + reflection** | Which decision I will make because of my data (e.g. ban map X, stop after 23:00). What I'd do next (Premier data, follow a tip for a week). What I learned. |
| 14:15–15:00 | **Wrap-up** | One-sentence takeaway: "Data turned a feeling ('I'm bad on Nuke') into proof, and proof into a plan." Show GitHub + app link. |
